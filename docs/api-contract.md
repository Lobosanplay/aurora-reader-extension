# Backend boundary (future phase)

Phase 1 makes no HTTP requests and has no API client or DTOs; it does not use environment variables. `.env.example` only notes a possible future public API origin and is not needed to build Phase 1. Tentative routes in the separate `aurora-reader-api` service: `POST /api/v1/translate`, `POST /api/v1/ask`, `POST /api/v1/transcribe`. Request/response shapes, provenance, failure codes and authorization are **not agreed**. Define typed DTOs and runtime validation in `src/types/api.ts` / `src/services/api-client.ts` only once the backend contract is settled. Any future `VITE_API_BASE_URL` is a public origin, never a secret; permission scope must match that origin. Current-page text and microphone audio require explicit consent before upload.
